# EnablementPage 视觉与交互全面优化 — 设计规格说明

**日期：** 2026-06-07  
**状态：** 已确认，待实施  
**范围：** `src/components/marketing/EnablementPage.tsx`

---

## 一、设计目标

在保持现有功能完整的前提下，从四个维度优化赋能培训中心页面：

1. **视觉层级与品牌感** — 统一色彩规范、卡片精细化、雷达图增强
2. **信息架构与清晰度** — 课程卡片瘦身、按钮优先级、学习路径流线化
3. **交互效率** — 筛选搜索、可交互雷达图、空状态设计
4. **个性化与激励** — 能力排名、进度解锁、智能推荐

## 二、确认的设计决策

### 2.1 顶部区域

| 子区域 | 决策 | 说明 |

## 三、组件架构

当前 `EnablementPage.tsx` 是 437 行的单体组件。优化时将提取以下子组件：

```
src/components/marketing/
├── EnablementPage.tsx              # 页面容器（~150 行）
├── enablement/
│   ├── EnablementHeader.tsx        # 页头：模式切换 + 角色选择
│   ├── KpiCards.tsx                 # 顶部 4 个 KPI 指标卡片
│   ├── SkillRadar.tsx              # 能力雷达图（可交互）
│   ├── LevelBadge.tsx             # 等级勋章卡片
│   ├── LearningPathBanner.tsx      # 学习路径步骤条
│   ├── CourseFilterBar.tsx         # 筛选器（搜索 + 下拉）
│   ├── CourseCard.tsx              # 单门课程卡片
│   ├── CourseGrid.tsx              # 课程卡片网格
│   ├── RecommendationStrip.tsx     # 横向推荐滑动条
│   ├── PointsStore.tsx             # 积分商城网格
│   ├── EmptyState.tsx              # 空状态（引导型 + 无结果）
│   ├── AssessmentModal.tsx         # 评估弹窗
│   ├── FeedbackModal.tsx           # 反馈弹窗
│   └── AdminOverview.tsx           # 管理员总览面板
```

**原则：** 每个子组件职责单一，通过 props 接收数据，不直接访问 Supabase。

- 点击维度触发父组件回调，由父组件设置课程筛选

- 右侧「继续下一课」快捷按钮

## 五、深色模式关键决策

1. **卡片背景** `slate-800` (#1e293b)，阴影加深并降低不透明度
2. **边框补偿**：暗色下阴影不可见，用 `border-slate-700` 区分卡片边界
3. **渐变图标**：渐变色彩亮度提升 10-15% 以补偿暗色背景
4. **文字层级**：标题 slate-100 / 正文 slate-300 / 辅助 slate-500
5. **进度条背景**：`#334155`（slate-700）
6. **遵循现有 Tailwind `dark:` 前缀模式**，与项目其他页面保持一致

## 六、交互行为

### 6.1 雷达图交互

- 点击维度标签（技术/销售/市场）→ 自动筛选课程列表显示对应分类课程
- hover 数据点 → 显示具体分值 tooltip
- 维度标签 hover → 浅底色高亮

### 6.2 筛选器行为

- 搜索框：实时过滤课程名称（防抖 300ms）
- 状态下拉：未开始 / 进行中 / 已完成
- 类型下拉：全部 / 必修 / 选修
- 难度下拉：全部 / 初级 / 中级 / 高级
- 筛空时显示空状态（引导清除筛选）

### 6.3 课程操作优先级

| 优先级 | 操作 | 样式 |
|--------|------|------|
| 1 (Primary) | 继续学习 / 开始学习 | 全宽实色渐变按钮 |
| 2 (Secondary) | 评估 | 文字链接 |
| 3 (Tertiary) | 反馈 | 文字链接 / 图标 |

### 6.4 空状态

- **无课程**：大插画 +「开始能力评估」CTA + 「浏览课程体系」备选
- **筛空**：说明原因 +「清除筛选」次按钮 +「浏览全部课程」主按钮

## 七、数据流

保持现有 Supabase 数据源不变：
- `certification_programs` → 课程列表
- `user_enrollments` → 用户学习记录
- `assessment_records` → 评估历史
- `course_feedback` → 课程反馈

**Props 传递链：**
```
EnablementPage (data fetching + state)
  ├─> EnablementHeader (mode, role, name)
  ├─> KpiCards (stats)
  ├─> SkillRadar (scores, onDimensionClick)
  ├─> LevelBadge (level, progress)
  ├─> LearningPathBanner (role, completedCount, totalCount)
  ├─> CourseFilterBar (filters, onChange)
  ├─> CourseGrid (filteredPrograms, enrollments)
  │     └─> CourseCard (program, enrollment, onStartAssessment, onFeedback)
  ├─> RecommendationStrip (recommendedPrograms)
  └─> PointsStore (earnedPoints, storeItems)
```

## 八、需要确认的开放项

1. **课程封面图标映射**：当前使用 `FRAMEWORK[p.category].icon`，是否增加每个课程独立 icon 字段到数据库？
   - 默认方案：按分类使用 FRAMEWORK 图标，后续可扩展 per-course icon

2. **「击败全国 X%」数据来源**：当前 mock 为固定值，是否需要后端提供真实排名接口？
   - 默认方案：使用 `earnedPoints / totalPoints` 在本地计算百分位（伪排名）

3. **推荐算法**：第一期使用「同分类未选修 + 热门排序」简单规则
   - 后续可接入 AI 推荐
