# EnablementPage 管理员视图深度优化 — 设计规格说明

**日期：** 2026-06-07  
**状态：** 已确认，待实施  
**范围：** `src/components/marketing/EnablementPage.tsx` 管理员模式全部标签页

---

## 一、设计目标

将管理员视图从**信息展示板**转变为**管理控制台**，提供洞察力（数据趋势）、干预能力（一键操作）、效率工具（搜索/筛选/导出/对比）。

核心原则：
- 每个数字背后有趋势（Sparkline）
- 每个列表项可动作（催办/导出/下架）
- 支持按课程和按公司双维度管理

---

## 二、确认的设计决策

### 2.1 KPI 数据看板

| 指标 | 当前 | 优化后 | 新增能力 |
|------|------|--------|----------|
| 总学员 7人 | → | **活跃学员占比 71%** | Sparkline 趋势 + 环比 ↑5% |
| 完成率 58% | 保留 | **完课率 58%** | Sparkline 趋势 + 环比 ↑8% |
| — | 新增 | **预警中心** | 滞后人数 + 低分课程数合并展示 |
| 课程反馈 5条 | → | **学员反馈 4.3/5** | 低分条数标签 + 点击跳转 |

- **预警中心**：红色边框，显示「4 人滞后 7天+」+「2 课程低分 ＜3⭐」，点击跳转对应筛选
- **Sparkline**：每张卡片右上角 60×24px 迷你 SVG 折线图，展示近 4 周趋势
- **点击交互**：活跃占比卡片 → 筛选本周活跃用户；反馈卡片 → 跳转 feedbackTab + 定位低分

### 2.2 课程管理列表

| 功能 | 实现 |
|------|------|
| **学员布局** | 横向 Chip（头像名+公司+分数标签），默认展示 5 人，「+ 展开 N 人」按钮 |
| **状态标签** | 绿色 = 已完成(高分) / 蓝色 = 进行中 / 红色虚线边框 = 已逾期(进度<50%且7天无活动) |
| **分数显示** | 已完成学员 Chip 上直接显示分数（如「92分」），进行中显示进度百分比 |
| **一键催办** | 每个课程标题右侧按钮，筛选该课程下 progress < 50% 的学员并发送通知 |
| **搜索筛选栏** | 搜索框（学员姓名/公司）+ 状态下拉 + 必修/选修下拉 + 导出 Excel 按钮 |
| **课程健康度** | 绿色圆点(完课率>60%) / 黄色(30-60%) / 红色(＜30% 或 0人)，融于课程卡片左侧指示器 |
| **空课引导** | 0 人报名课程置灰 + "📨 邀请学员" 按钮替代空文案 |

### 2.3 公司维度视图

| 功能 | 实现 |
|------|------|
| **视图切换** | 顶部 Chip 切换：「📚 按课程」/「🏢 按公司」 |
| **公司行** | 首字头像 + 公司名 + 人数/完成/平均分 + 能力维度分数标签 + 「对比」入口 |
| **活跃度标签** | 🥇最活跃(绿) / 中(默认) / ⚠️需关注(红) |
| **雷达对比** | 点击「对比」→ 该公司能力多边形 vs 平台平均(灰色虚线)，优劣势标注(+15/-8) |
| **干预按钮** | 低活跃公司行红色高亮 + 「干预」按钮（快速发送激励通知） |

### 2.4 流程自动化

| 功能 | 实现 |
|------|------|
| **导出 Excel** | 筛选栏右侧按钮，导出当前过滤结果（姓名、公司、课程、进度、分数、状态）为 .xlsx |
| **证书配置** | 课程行头右侧「📜 证书」按钮，弹窗设置：通过分数阈值、证书模板、自动发放开关 |
| **截止日期** | 课程行右侧「📅 截止: YYYY-MM-DD (N天)」，逾期红色高亮 |

### 2.5 悬浮详情 (Hover Tooltip)

- 触发：鼠标悬浮学员 Chip 300ms
- 内容：入职时间、考核通过率、大区负责人、选课/完成数、最近活跃时间
- 快捷操作：「查看详情」按钮 + 「📧 发送提醒」按钮
- 样式：白色卡片 + 三角箭头，shadow-2xl

### 2.6 反馈分析标签页

| 板块 | 内容 |
|------|------|
| **评分分布** | 5 级评分柱状图（1-5⭐ 各几条），综合评分 + 总评价数 |
| **关键词云** | 基于反馈内容自动提取，字号 = 出现频率，颜色区分情感（正面蓝绿 / 负面红橙） |
| **低分高亮区** | 红色背景卡片展示 ≤2⭐ 的反馈原文，便于管理员快速定位问题 |

### 2.7 课程性能排序

- 排序 Chip：完课率 ↓ / 好评率 / 选课人数 / 课程时长
- 排名列表：前三名绿色/蓝色/默认，末尾（完课率=0）红色高亮
- 末尾课程：显示「下架?」按钮（二次确认弹窗）

## 四、数据流

### 4.1 现有数据源（不变）

- `certification_programs` → 课程
- `user_enrollments` → 选课（含 `last_activity` 用于计算活跃度/滞后）
- `assessment_records` → 评估记录
- `course_feedback` → 反馈

### 4.2 新增计算逻辑

| 指标 | 计算方式 |
|------|----------|
| 活跃学员占比 | `enrollments.filter(e => 7天内 last_activity).map(e => e.user_name).去重 / 总学员` |
| 进度滞后 | `enrollments.filter(e => progress < 50% && 7天无 last_activity)` |
| 课程健康度 | 完课率 = completedCount / enrollmentCount；阈值 >60%绿 30-60%黄 <30%红 |
| 公司活跃度 | 按公司聚合：选课数 + 完课率 + 平均分，平台百分位 >70% 高 <30% 低 |
| 反馈关键词 | 前端简易实现：对 `content` 做中文分词（按标点切割），统计词频，top 15 展示 |
| Sparkline 数据 | 基于 `last_activity` 按周聚合活跃数，取最近 4 周 |

### 4.3 导出 Excel 数据结构

| 列 | 来源 |
|----|------|
| 学员姓名 | `user_enrollments.user_name` |
| 所属公司 | `user_enrollments.company` |
| 课程名称 | `certification_programs.name` |
| 学习进度 | `user_enrollments.progress` |
| 评估分数 | `user_enrollments.score` / `assessment_records.score` |
| 状态 | `user_enrollments.status` (中文映射) |
| 最近活动 | `user_enrollments.last_activity` |

## 六、交互行为

### 6.1 KPI 卡片点击

- 活跃学员占比 → 筛选课程列表仅显示本周活跃用户
- 预警中心 → 跳转课程列表 + 预筛选 `status=stagnant`
- 学员反馈 → 跳转 feedbackTab + 自动滚动到低分区

### 6.2 催办流程

1. 点击「⚡ 一键催办」→ 确认弹窗："将向 N 名进度低于 50% 的学员发送学习提醒"
2. 确认 → 调用 `supabase` 写入通知表（如 `partner_operation_logs`）+ Toast 提示
3. MVP 阶段：前端 Toast + console.log（后端通知暂不强制）

### 6.3 导出流程

1. 应用当前筛选条件到数据
2. 前端生成 CSV（或 xlsx 通过 SheetJS）
3. 触发浏览器下载 `培训进度报表_YYYY-MM-DD.csv`

### 6.4 空状态

- 筛选无结果 → "未找到匹配的学员" + 「清除筛选」按钮
- 某课程 0 人 → 卡片置灰 + 「📨 邀请学员」按钮
